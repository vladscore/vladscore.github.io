Data practices

Privacy & Cookies

A concise account of what this static website stores, what it does not collect, and what its hosting providers may process.

No audience tracking

Vlad Score does not use advertising trackers, behavioural profiling, analytics pixels or a site-operated visitor database. The release-notification field is currently inactive: submitting it does not transmit or store the address entered.

Local listening preferences

The music player uses the browser’s local storage to remember only two settings on the visitor’s own device:

  • the last playback position;
  • the selected playback volume.

These values are functional, contain no name or account identifier, and are not transmitted to the site publisher. They can be removed by clearing site data in the browser.

Hosting data

The site is delivered by GitHub Pages. GitHub states that a visitor’s IP address is logged and stored for security purposes. GitHub is responsible for that hosting-side processing under its own Privacy Statement.

Fonts and external destinations

The design requests typefaces from Google Fonts. The visitor’s browser therefore connects to Google’s servers to retrieve those files, subject to Google’s own privacy terms. Links to Amazon, GitHub documentation and other external destinations open services with independent privacy practices.

Cookies

The site’s own code does not set cookies. Hosting or external-service providers may apply their own technical measures under their respective policies. Because the site does not deploy advertising or analytics cookies, it does not display a consent banner for such trackers.
